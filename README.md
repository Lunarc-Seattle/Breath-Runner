# Gamified Breathing Training for Lung Recovery at Home — 12-Page Web Platform

**Designer & Developer:** Jie (Fia) Yin  
**Stack:** React 18 (ES Modules) • Node.js & Express REST API • C++20 Airflow DSP • Python Telemetry CI

A 12-page interactive companion web application for a smart breathing trainer: Bluetooth device pairing, digital spirometry lung-capacity tests, map-based breathing games (Forest Level 1), multiplayer co-op training, hospital device rental, 4-part disinfection booking, physician telehealth, community leaderboards, and recovery badges.
